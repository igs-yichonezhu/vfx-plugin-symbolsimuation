# 從盤面圖讀出盤面

開發人員會給遊戲截圖、企劃分鏡或手畫的盤面。目標是轉成工具的文字格式：

```
每一行 = 一列（由上到下），每行 = 輪數個符號名稱（由左到右）
SEVEN SEVEN SEVEN WILD Q
```

## 步驟

1. **先認符號。** 執行 `node tools/sfs.js symbols-sheet <符號資料夾> <工作資料夾>/symbols.png`，用 Read 看這張總覽圖，記住每個符號名稱長什麼樣子（顏色、形狀、文字）。名稱不好認或太長時，用 `symbol P <名稱> --rename <短名>` 改成好打的名字（WILD、SC、7、A…）。
2. **確認盤面範圍。** 找出轉輪視窗：幾輪（直排）× 幾列（橫排）。視窗上下露出的半顆符號**不算**盤面；如果遊戲有露出，記下來設定 `layout.peek`。
3. **逐格讀。** 由左到右一輪一輪讀，每輪由上到下。遇到這些情況要特別注意：
   - 符號上有中獎特效 / 光暈 / 數字遮住：以符號本體判斷。
   - 長條 / 疊加 / 擴展符號（一個圖蓋住同一輪好幾格）：工具每格一個符號，請和開發人員確認要怎麼拆（通常每格填同一個符號）。
   - 認不出來、或符號庫裡沒有這個圖：**不要猜**，列出位置問開發人員。
4. **寫入：** `node tools/sfs.js board P --end "第1列 / 第2列 / 第3列"`（起始盤面用 `--start`）。
5. **比對：** `node tools/sfs.js render P --boards <工作資料夾>/boards.png --scale 0.4`，用 Read 看產生的圖，跟開發人員給的圖一格一格比對，有錯就改。
6. **給開發人員確認。** 回報文字格子（比圖好核對），例如：

   ```
   結果盤面（5×3）：
   CHERRY  SCATTER  BELL     K     SCATTER
   SEVEN   SEVEN    SEVEN    WILD  Q
   J       A        SCATTER  BAR   A
   ```

## 起始盤面

- 開發人員有給就照給的。
- 沒給的話：用一個「看起來普通、不會中獎、也不會先讓人期待」的盤面（不要有 Scatter、不要有連線），可以用 `board P --start "..."` 自己排，或保留 `init` 時的亂數盤面，但要檢查沒有意外的連線。
- 如果假轉是接在上一段影片後面，起始盤面要跟上一段最後的畫面一樣，記得問。

## 只有一張圖時

開發人員常只給「結果」截圖。結果盤面照圖讀；起始盤面依上面規則產生，並在回報時說明「起始盤面是我排的」。
