# 案例：Spicy Fortunes 假廣告（模仿競品實機錄影）

輸入：競品實機錄影（134 秒，直式）＋素材資料夾（MG / FG / 轉輪1 / 轉輪2 / 三個碗 / 雙辣椒 / 曲面機台 PSD、雙辣椒連續圖、角色與特效影片、音效）。
成品：29.5 秒、1080×1920、30fps。範本 `templates/` 就是這個案子的最終版（v4）。

## 分鏡（v4）
| 秒 | 畫面 | 做法 |
| --- | --- | --- |
| 0 ~ 1.4 | 主遊戲畫面（照 MG.psd） | 圖層全照 PSD 位置；0.8 ~ 1.35 辣椒人往右下讓開，露出後面的轉盤 |
| 1.4 ~ 6.6 | 轉盤（轉輪1，MG 內嵌那份）轉動 → 停在 MINOR，GRAND 差 7° | 13 格、每格 27.69°；拉回 → 加速 → 等速 → 冪次減速（p = 3.2）；指針被格線撥動（表達式） |
| 7.4 ~ 10.5 | MINOR JACKPOT AWARDED → 4,000 CREDITS | 壓暗、放射光、跑分表達式、金幣 |
| 10.35 ~ 11.1 | 綠鑽衝向鏡頭 + 白光 | 綠鑽影片去黑底、放大 |
| 11.2 ~ 19.0 | 免費遊戲：三回合，符號從上方碗那排帶彩色殘影飛入落格 | SlotFakeSpin Hold & Spin 只拿時間（盤面隱藏）；辣椒格落地播「長出火框」連續圖、之後燒；雙鑽、三色寶石（從同色的碗飛出）彈出 |
| 19.3 ~ 21.6 | 辣椒人噴火（張嘴影片）→ 辣椒格變燒紅底板 + 數值 → 寶石出數值 | 火焰影片 Add、往下噴辣椒那一欄 |
| 21.6 ~ 22.7 | 依序收分 | 數值跳一下 |
| 22.7 ~ 29.5 | BIG WIN 30,420 | SlotFakeSpin 報獎，標題換 BIG WIN 圖、放射光、彩帶、星光；停到片尾 |

鏡頭：停輪、彩金、噴火、BIG WIN 瞬間推近 4 ~ 6% 再回彈。

## 版本歷程（開發人員指出的問題 → 原因）
| 版本 | 問題 | 原因 → 修正 |
| --- | --- | --- |
| v1 | 圖沒有對好（轉輪框） | 設父層後子層縮放被改；燒的辣椒格小 38%；用錯轉盤；碗和石板自己排 → 設父層後重設、`calibrate.py`、換轉輪1、照 PSD 位置 |
| v2 | 符號表演不一樣 | 競品是「飛入落格再變色塊」，做成了原地轉 → 改飛入 |
| v3 | 符號只有兩種 | 只用了亮的特殊符號 → 加三色寶石 |
| v4 | — | 還缺：競品的綠 / 金叉叉色塊、細光軌、機台招牌、火焰轉場 |

## 量出來的數字（換案子時重量）
- FG 格子：5 欄 × 6 列，欄距 200、列距 199，盤面中心 (539.5, 1146.5)。
- 辣椒格在 PSD 上 = 格子中心 + (-5, -7.5)，原尺寸（CHILI.png 內含偏移）。
- 雙辣椒連續圖對靜態格：opening 126.5% / 中心 -27px，in 127% / -29px，底板 136% / (+2, -13)px（相對輸出時縮成 25% / 82% 的連續圖）。
- MG 的轉輪1：畫布中心 (540.5, 957)、縮放 120.77%。
