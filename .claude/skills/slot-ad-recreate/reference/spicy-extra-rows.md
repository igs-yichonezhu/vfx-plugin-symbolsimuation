# 案例：Spicy Fortunes「EXTRA ROWS」假廣告（第二支競品）

輸入：競品錄影（177 秒，直式 60fps，YouTube shorts 實機）＋同一包 Footage（3_Picture、2_Video）＋基礎素材包（金幣、爆圈）。
成品：29.5 秒。範本 `templates/make_ad_extrarows.js`（時間表 / 盤面 / 數值）、`templates/director.jsx`（共用）、`templates/prep_fx.py`（特效包切段、碗狀態）。
素材可以沿用第一個案子的 `kit/assets`（同一包 Footage），只補新的。

## 版本歷程（開發人員指出 → 修正）
| 版本 | 問題 | 修正 |
| --- | --- | --- |
| v1 | 轉盤中獎框沒對正 | 停在 +3 正中間（不要為了差一點停在邊緣） |
| v1 | FG 盤面、落下內容和競品不一樣，符號有缺 | 盤面照競品排；綠 / 金格用紅雙辣椒格轉色相；空格底下補壓暗符號；寶石 UPGRADE |
| v2 | 素材沒全部用上 | 補碗狀態、角色待機 / 開心影片、能量特效包、配樂音效 |
| v3 | 特效要滿版、基礎素材包也要用 | `full()` 黑底特效滿版；金幣、爆圈 |
| v4 | 不合的素材不要硬塞（例：火焰） | 只留競品有的：噴火滿版、BIG WIN 特效；拿掉轉盤滿版篝火、紫火、停輪爆圈等 |
