# 素材清單與交檔規格

回報「缺什麼」時照這份的分類寫。素材「有給但沒用」也要列，並寫原因（競品沒有這個效果 / 和畫面不合）——不合的不要硬塞。

## 必給（沒有就做不出來）
| 項目 | 用途 |
| --- | --- |
| 競品參考影片 | 流程、節奏、每段多長、符號怎麼表演 |
| 主遊戲分層 PSD | 背景、角色、轉輪框、符號、上下 UI（照 PSD 對位） |
| 轉盤分層 | 盤面獨立一層（才能轉）；指針、圓心、選擇框、橫幅各一層 |
| 免費遊戲 / 特色遊戲分層 PSD | 背景、格子框、角色、特殊符號、一般符號 |
| 報獎美術 | BIG WIN 等標題圖、放射光 |
| 音樂與音效 | 背景音樂、轉盤轉動、指針答答、停輪、彩金、落格、特效、BIG WIN |
| 演出內容（文字） | 轉盤停哪格、彩金多少、每回合落什麼在哪、各格數值、總分、片長上限；不給就照競品自己訂，回報時寫出來 |

## 建議給（沒有也做得出來，效果會差）
| 項目 | 沒有的話 |
| --- | --- |
| 特殊符號動畫（出現 / 待機的連續圖） | 只能靜態彈出 |
| 角色動畫（待機、觸發、開心） | 靜態圖 + 輕微呼吸 |
| 特效（火焰、星光、彩帶、閃光、轉場） | 內建形狀 |
| 符號的動態版 | 靜態圖飛入 |
| 機台框（綠幕） | 只出遊戲畫面 |

## 交檔規格
1. 圖層效果先點陣化，或另外給 PNG（psd-tools 畫不出圖層效果）。
2. 會動的東西分層（盤面 / 指針 / 圓心分開）。
3. 影片給帶透明的（ProRes 4444），不要純色底。
4. 連續圖檔名編號結尾（`xxx_00000.png`），一個動作一個資料夾。
5. 所有畫面同一個畫布尺寸（例如 1080×1920）。
