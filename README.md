# SlotFakeSpin 老虎機假轉工具（After Effects 外掛）

匯入老虎機符號（圖騰）→ 指定 **起始盤面** 與 **轉完的結果盤面** → 一鍵在 AE 合成裡生成轉輪動畫。

![預覽](docs/preview.gif)

> 上圖是用工具算出的同一組關鍵影格，在 Node 裡模擬畫出來的預覽（`tools/preview.js`），不是 AE 算圖。

## 功能

- **符號庫**：整個資料夾匯入（PNG / JPG / PSD / TGA / TIFF…，檔名 = 符號名），也可以把專案裡的素材或 **合成（動態符號）** 加進來。
- **盤面編輯**：可自訂輪數 × 列數（例如 5×3、6×4），點格子填入符號、Alt+點吸取、Shift+點整輪填入；也可以用文字輸入或直接從 Excel / Google 試算表貼上。
- **轉動手感**：起轉反向拉回 → 加速 → 等速 → 減速 → 衝過頭回彈，每一輪依序停下。可以設定 **期待延遲**（聽牌時後面幾輪轉久一點）。
- **乾淨的關鍵影格**：每一輪只有一顆 null（`STRIP_CTRL`）的 Y Position 有 5~6 個關鍵影格，全部對齊影格、速度連續，graph editor 裡好調。
- **填充符號控制**：可以設定哪些符號不要被亂數帶出來（例如 Scatter / Bonus），只出現在你指定的盤面上。亂數種子固定，同一組設定每次結果相同。
- **音效對點**：盤面圖層上會打標記 `SFS SPIN`、`SFS R1 STOP`…`SFS ALL SETTLED`。
- **可回頭修改**：設定會存在盤面合成裡。選取盤面圖層 →「讀取選取盤面」可以把當時的設定讀回來；改完按「更新選取盤面」會原地重建（圖層位置、上面加的特效都保留）。
- 動態模糊（含快門角度）、向上 / 向下轉、上下露出半顆符號、輪距 / 列距。

## 安裝

1. 下載 [`dist/SlotFakeSpin.jsx`](dist/SlotFakeSpin.jsx)。
2. 複製到 AE 的 ScriptUI Panels 資料夾：
   - Windows：`C:\Program Files\Adobe\Adobe After Effects <版本>\Support Files\Scripts\ScriptUI Panels\`
   - macOS：`/Applications/Adobe After Effects <版本>/Scripts/ScriptUI Panels/`
3. 重開 AE，從選單 **視窗（Window）→ SlotFakeSpin.jsx** 打開，可以停駐在任何位置。

不想安裝也可以用 **檔案 → 指令碼 → 執行指令碼檔案…** 直接執行，會開一個浮動視窗。

> 只有「存設定… / 開設定…」需要寫檔權限：**偏好設定 → 指令碼與運算式 → 勾選「允許指令碼寫入檔案及存取網路」**。其他功能不需要。

## 使用流程

1. **1 符號**：按「匯入資料夾…」選你的符號圖檔資料夾（可以先用 `examples/symbols` 試）。
   - `●` = 填充符號（轉動中會亂數出現），`○` = 不當填充。選取後按「切換填充」或雙擊切換。
   - 「改名」可以把符號改成短名稱（例如 `WILD`、`7`），文字輸入盤面時比較好打。
2. **2 盤面**：上方切換「起始盤面 / 結果盤面」，選畫筆後點格子。
   - 第一次匯入時兩個盤面會先亂數填好，直接改你要的格子就好。
   - 「文字編輯…」格式：每一行是一列（由上到下），每行放「輪數」個符號：
     ```
     SEVEN SEVEN SEVEN BAR  BELL
     WILD  WILD  WILD  A    K
     Q     J     SCATTER A  A
     ```
     名稱有空白時改用逗號或 Tab 分隔（從試算表複製貼上就是 Tab）。
3. **3 動態**：在時間軸移到要開始轉的位置，按「取目前時間」。下方會即時顯示每一輪的停輪時間。
4. 按 **▶ 建立假轉**。盤面會放在目前合成的正中央（或在「4 版面」改成輸出到新建合成）。

## 產生的內容

```
專案
└─ SlotFakeSpin/
   ├─ SFS_Symbols/          匯入的符號素材
   └─ SFS_Board_01/
      ├─ SFS_Board_01       盤面合成（放進你的合成；設定存在它的註解裡）
      ├─ SFS_Board_01_R1    第 1 輪轉輪合成（合成大小 = 轉輪視窗，自動裁切）
      ├─ ...
      └─ SFS_Board_01_R1_null ...
```

每個轉輪合成內：

| 圖層 | 說明 |
| --- | --- |
| `STRIP_CTRL` | null，帶動整條轉帶，Y Position 上有全部的動畫關鍵影格 |
| `R1_S01_A`（綠色標籤） | 起始盤面第 1 列 |
| `R1_E01_WILD`（紅色標籤） | 結果盤面第 1 列 |
| `R1_F07_K` / `R1_B01_Q` | 轉動中經過的填充 / 緩衝符號（設為 shy，時間軸預設隱藏） |

想單獨換掉某一顆符號：在轉輪合成裡選那個圖層，Alt（Mac：Option）+ 拖曳新素材取代即可。

## 參數

| 位置 | 參數 | 說明 | 預設 |
| --- | --- | --- | --- |
| 動態 | 開始時間 | 開始轉動的時間（秒，目標合成時間） | 0 |
| 動態 | 第一輪停 | 從開始到第 1 輪「停輪」的秒數。停輪 = 衝到最遠點那一刻，適合對音效 | 1.0 |
| 動態 | 每輪間隔 | 每一輪停下的間隔 | 0.25 |
| 動態 | 期待延遲 | 各輪額外延遲，逗號分隔，例如 `0,0,0,0.8,0.8`。延遲會累加到後面的輪 | 空 |
| 動態 | 轉速 | 等速段每秒經過幾格。實際轉速會微調成整數格（下方會顯示） | 18 |
| 動態 | 方向 | 向下 / 向上 | 向下 |
| 動態 | 起轉拉回 | 開始前反方向拉的距離（格）與時間（秒），0 = 不拉 | 0.25 格 / 0.15 秒 |
| 動態 | 加速 / 減速時間 | 起轉加速、停輪前減速的時間。減速越短停得越乾脆 | 0.15 / 0.08 |
| 動態 | 停輪衝過 / 回彈 | 停輪時衝過定位的距離（格）與彈回去的時間，0 = 不回彈 | 0.15 格 / 0.2 秒 |
| 動態 | 亂數種子 | 決定填充符號的排列 | 1 |
| 動態 | 動態模糊 / 快門角度 | 開啟轉輪合成與符號圖層的動態模糊 | 開 / 180 |
| 版面 | 格寬 / 格高 | 每一格的尺寸 px | 200 × 200 |
| 版面 | 輪距 / 列距 | 輪與輪、上下符號之間的間距 px | 10 / 0 |
| 版面 | 上下露出 | 轉輪視窗上下多露出的高度（看得到半顆相鄰符號） | 0 |
| 版面 | 符號縮放 | 符合格子（等比縮放放進格子）或原始尺寸，再乘上 % | 符合格子 100% |
| 版面 | 輸出到 | 目前合成 / 新建合成（新合成用設定的 fps） | 目前合成 |

## 動作原理（給想改程式的人）

每一輪是一條轉帶，向下轉時由上到下排成：

```
[緩衝 b 格][結果盤面][填充 N 格][起始盤面][緩衝 b 格]
```

一開始畫面看到起始盤面，null 往下移 (列數 + N) 格後剛好看到結果盤面。N 由「轉速 × 時間」反推並取整數，再回頭算出精確的等速 v，所以停輪位置一定分毫不差。

關鍵影格 `K0 開始 → K1 拉回 → K2 加速完成 → K3 開始減速 → K4 停輪（衝過頭） → K5 定位`，Bezier 影響值用 33.33% 時，加速 / 減速段會是精準的等加速度、中段是精準的等速，所以速度在每個關鍵影格都連續。

## 開發

```
src/core.js     純邏輯：設定、盤面、JSON、亂數、轉帶與關鍵影格計算（可在 Node 測試）
src/ae.js       AE DOM：匯入、建立合成 / 圖層 / 關鍵影格 / 標記、讀回設定
src/ui.js       ScriptUI 面板
src/main.js     進入點
tools/build.js  合併成 dist/SlotFakeSpin.jsx（ES3 文法檢查、移除註解、非 ASCII 轉 \uXXXX）
test/           模擬 AE 與 ScriptUI 的測試
```

```bash
npm install
npm test        # 建置 + 跑全部測試
npm run build   # 只建置 dist/SlotFakeSpin.jsx
node tools/preview.js "0,0,0,0,0.9" /tmp && python3 tools/preview_render.py /tmp/preview_frames.json examples/symbols docs/preview.gif
```

修改請改 `src/`，不要直接改 `dist/`。`dist/SlotFakeSpin.jsx` 全部是 ASCII，不受 Windows / macOS 語系編碼影響。

測試會在模擬的 AE 物件模型裡跑完整建置流程，用和 AE 相同的 Bezier 內插算出每個時間點畫面上的符號，驗證「開始前 = 起始盤面、停妥後 = 結果盤面」，並操作面板的每個按鈕。模擬環境不等於真的 AE，第一次使用請先在 AE 裡實際跑一次確認。

## 已知限制

- 盤面格子的縮圖只支援 PNG / JPG 符號；PSD、合成等會只顯示名稱。如果縮圖顯示怪怪的，可以在「2 盤面」取消勾選「縮圖」。
- 每一格是一個圖層，超大盤面（例如 12 輪、很長的轉動時間）建立時會比較久。
- 不支援跨格的大符號（例如 2×2 巨型符號）。
